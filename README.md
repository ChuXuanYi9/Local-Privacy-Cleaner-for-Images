📍 为什么你的照片正在出卖你？ 一张普通的手机原图，不仅包含画面，还隐藏着精确到米级的 GPS 坐标、拍摄设备型号、镜头参数甚至机身序列号。这些数据被社交平台压缩时往往会被保留，通过简单的反向地理查询工具就能还原出你的家庭住址、工作单位或出行轨迹。

✨ 本工具如何解决这个问题？ 「图片隐私清道夫」是一个完全运行在客户端的隐私清理工具。

真·本地处理：所有计算都在你的设备内存中完成，照片不会经过任何第三方服务器，适合对隐私极度敏感的用户。
全格式支持：原生支持 JPEG, PNG, WebP 以及高耗能的 HEIC/HEIF 格式，并针对 EXIF 结构进行了深度解析。
智能清理策略：提供分级开关，你可以选择性地清除 GPS 坐标、相机硬件指纹、时间戳或作者信息；同时也支持一键“无差别”清理。
无损画质：对于 JPEG 文件，采用直接剥离元数据段的方式，不重新编码，确保输出图片与原始画质完全一致。
极简交互：无需安装 App，无需配置环境，打开网页即可使用。支持拖拽、粘贴及批量导入，并在处理后自动进行二次复检，确保无残留。
